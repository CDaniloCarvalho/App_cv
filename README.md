# App CV

App CV é um sistema web desenvolvido com HTML, CSS, JavaScript e Vue.js. O objetivo deste projeto é permitir que os usuários gerem currículos personalizados. Os usuários podem preencher os dados de um formulário, visualizar os modelos de currículo disponíveis e gerar o seu currículo em PDF.

## Tecnologias Utilizadas

- **HTML5**: Utilizado para a estruturação do conteúdo web.
- **CSS3**: Utilizado para estilizar os elementos HTML, tornando a interface mais atraente e responsiva.
- **JavaScript (ES6)**: Utilizado para adicionar interatividade à aplicação.
- **Vue.js**: Framework JavaScript utilizado para construção de interfaces de usuário reativas e componíveis.

## Funcionalidades

- **Formulário de Dados**: Permite ao usuário preencher informações pessoais, experiências profissionais, educação e outras informações relevantes.
- **Modelos de Currículo**: Oferece modelos de currículo que o usuário pode visualizar antes de gerar o PDF.
- **Geração de PDF**: Gera o currículo preenchido em formato PDF, pronto para ser impresso ou compartilhado.
- **Responsividade**: Layout responsivo que se adapta a diferentes tamanhos de tela.

## Instalação e Execução

1. Clone o repositório:
    ```bash
    git clone https://github.com/CDaniloCarvalho/App_cv.git
    ```
2. Navegue até o diretório do projeto:
    ```bash
    cd app-cv
    ```
3. Instale as dependências:
    ```bash
    npm install
    ```
4. Execute a aplicação:
    ```bash
    npm run serve
    ```
